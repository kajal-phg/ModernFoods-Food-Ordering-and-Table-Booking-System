# ModernFoods – Food Ordering and Table Booking System

## About the Project

ModernFoods is a responsive restaurant website developed using HTML, CSS, and JavaScript. The project provides an interactive platform where users can explore food items, browse the restaurant menu, place food orders, and book tables through a simple and user-friendly interface.

## Features

- Responsive website layout
- Modern restaurant homepage
- Interactive food menu
- Food ordering interface
- Table booking functionality
- Attractive food cards and images
- Interactive navigation
- User-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
